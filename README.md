# Immortal Snail 🐌

[This is my entry](https://immortal-snail.webflow.io/) built for the [Best Landing Page GSAP Hackathon](https://codetv.link/gsap-hackathon) hosted by [CodeTV](https://codetv.dev/)!

## What is this?

This is a fun and lightly threatening landing page built off of this [Astro + GSAP template](https://github.com/webflow-examples/astro-gsap), and based on the [immortal snail meme](https://knowyourmeme.com/memes/immortal-snail).

What if you received $10 million and immortality, but a snail was trying to kill you until the end of time?
